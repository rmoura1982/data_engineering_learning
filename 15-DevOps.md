# 15. Azure DevOps

Plataforma da Microsoft que reúne ferramentas para o desenvolvimento e a entrega de software. Entre as principais funcionalidades, oferece o `Azure Repos`, que é um sistema de controle de versão baseado em Git. Permite realizar deploys e automatizar testes e builds com base no código versionado por meio do `Azure Pipelines`. Conta também com o `Azure Boards`, que ajuda a organizar tarefas, acompanhar bugs, entregas e o andamento do projeto. O `Azure Test Plans` que permite o planejamento e a execução de testes manuais e automatizados. Já o `Azure Artifacts` é usado para armazenar e compartilhar pacotes como npm, NuGet, entre outros.

---

## Prós e Contras

**✅ Prós:**  
- Integração completa com outras ferramentas Microsoft.  
- Plataforma unificada para todo o ciclo de vida do desenvolvimento.  
- Automatização de processos com pipelines flexíveis.

**❌ Contras:**  
- Pode ser complexo para quem está começando.  
- Algumas funcionalidades avançadas exigem planos pagos.  
- Curva de aprendizado para integração com serviços externos.
